# Codex Working Notes

## Planning Convention

When a user asks Codex to create, refine, or present an implementation plan for this project, also save the plan as a Markdown file in the `plan/` directory.

Use this naming format:

```text
plan/YYYY-MM-DD-short-topic.md
```

Examples:

```text
plan/2026-07-23-day-1-foundation.md
plan/2026-07-24-auth-api-plan.md
```

Each plan file should include:

- Title
- Summary
- Key implementation changes
- Test plan
- Assumptions or decisions

If the user only asks a quick question and no actual plan is created, do not create a plan file.
